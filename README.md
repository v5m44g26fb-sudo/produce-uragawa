# 担当をデビューさせる件

実在のサバイバルオーディション番組『PRODUCE 101 JAPAN』Season1（2019・日プ無印）を題材にした、スマホ風SNSゲーム（ファンメイドのIF作品）。
プレイヤーは番組ADの「なお」。担当練習生・井汲大翔の史実（第2回順位発表36位、あと1枠差の脱落）を覆し、デビュー圏11位へ押し上げるため、
トーク・編集会議（分量配分）・順位発表を通して番組の裏側を動かしていく。

## 遊び方
`index.html` をブラウザで開くだけで遊べます（セーブは localStorage）。
v2の範囲：プロローグ（2019年8月・坡州で配属、Team DKと初対面）→ レベル分け評価（Team DK「Love so sweet」）→ ツカメ再評価（大翔C→D降格）→ ポジション評価（「OVER THE TOP」1組）→ 編集会議 → 放送・第1回投票 → 第1回順位発表。

## 仕組み
- 登場練習生は実在のS1練習生33名（Team DK全員、プチメン、川尻蓮・豆原一成ら主要組、「OVER THE TOP」「Everybody」のチームメイト等）
- 各人に能力4軸（ボーカル／ダンス／ラップ／ビジュアル）＋注目度、クラス推移（レベル分け→再評価）は史実準拠
- 第1回順位発表は、史実の得票（大翔19位・565,892票など資料で裏の取れる数値）を基準に、編集室の分量配分（12pt）と大翔への裏側サポート（信頼度・メンタル）の効果を反映して変動するIF仕様
- 投票の見せ方はS1の国民投票（11pick期）の文脈に準拠
- ひろとのボイスメッセージ付き（assets/vc-*.mp3、既存流用2本）
- 写真は番組公式サイト掲載の当時のプロフィール写真を使用（assets/s1/）

※本作品は実在の番組『PRODUCE 101 JAPAN』（2019）と実在の人物を題材にしたファンメイドのIF物語です。史実をもとにしていますが、登場人物の言動や順位の変動は創作を含みます。
