# 担当をデビューさせる件

サバイバルオーディション番組『新世界ステージ』の裏側を描く、スマホ風SNSゲーム。
プレイヤーは番組ADの「なお」。担当練習生・井汲大翔をデビュー圏内へ押し上げるため、
トーク・編集会議（分量配分）・順位発表を通して番組の裏側を動かしていく。

## 遊び方
`index.html` をブラウザで開くだけで遊べます（セーブは localStorage）。
v1の範囲：プロローグ（配属・初対面）→ 第1話（レベル分け評価）→ 編集会議 → 放送反応 → 第1回順位発表。

## 仕組み
- 練習生12名（能力4軸：ボーカル／ダンス／ラップ／ビジュアル＋注目度）
- 順位は ファン票50%＋オンライン30%＋現場票20% の合成で計算
- 編集室で分量ポイント（12pt）を配分すると注目度と票が動く
- ひろとのボイスメッセージ付き（assets/vc-*.mp3）
