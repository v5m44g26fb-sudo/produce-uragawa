# 担当をデビューさせる件

実在のサバイバルオーディション番組『PRODUCE 101 JAPAN』Season1（2019・日プ無印）を題材にした、スマホ風SNSゲーム（ファンメイドのIF作品）。
プレイヤーは高校3年生の制作インターン「なお」。合宿に帯同し、担当練習生・井汲大翔（17歳、学年は1つ下）の史実（第2回順位発表36位、あと1枠差の脱落）を覆し、デビュー圏11位へ押し上げるため、
トーク・編集会議（分量配分）・順位発表を通して番組の裏側を動かしていく。裏側サポートの積み重ねで、大翔との距離もゆっくり近づいていく。

## 遊び方
`index.html` をブラウザで開くだけで遊べます（セーブは localStorage。v2のセーブデータはそのまま第2部へ引き継げます）。
- 第1部：プロローグ（2019年8月・坡州で帯同開始、Team DKと初対面）→ レベル分け評価（Team DK「Love so sweet」）→ ツカメ再評価（大翔C→D降格）→ ポジション評価（「OVER THE TOP」1組）→ 編集会議 → 放送・第1回投票 → 順位発表直前の電話 → 第1回順位発表
- 第2部（v3で追加）：グループバトル編成（障害物リレー3位→「Everybody」獲得）→ 本番（チーム9位／大翔は個人2位・277票）→ 編集会議・第2ラウンド → 放送・第2回投票（週次33位への急落、浦野秀太と「死票」）→ コンセプト評価マッチング（「やんちゃBOY」仮センター）→ 発表前夜の電話 → 第2回順位発表（蓄積で生存／脱落に分岐。脱落した場合は第2部の始まりからIFをやり直せる）

## 仕組み
- 登場練習生は実在のS1練習生33名（Team DK全員、プチメン、川尻蓮・豆原一成ら主要組、「OVER THE TOP」「Everybody」のチームメイト等）
- 各人に能力4軸（ボーカル／ダンス／ラップ／ビジュアル）＋注目度、クラス推移（レベル分け→再評価）は史実準拠
- 順位発表は、史実の得票（第1回：大翔19位・565,892票／第2回：残留ライン35位・浦野秀太164,879票など資料で裏の取れる数値）を基準に、編集室の分量配分（各ラウンド12pt）と大翔への裏側サポート（信頼度・メンタル）の効果を反映して変動するIF仕様
- 投票の見せ方はS1の国民投票（11pick期）の文脈に準拠
- トークの配信と保存：場面の始まりに届くトークは、場面が未完のうちは保存されず、開き直すと1回だけ届く。場面途中の保存（選択肢タップ時）に巻き込まれても二重に届かないよう、冒頭のトークには冪等キーを付けている（v8.64で棚卸し・是正。結論はコード内の恒常メモに記録）
- アプリの挙動の実物寄せ（v8.65〜の「アプリ・リアル化」）：LINEの既読・一覧の並び・下書き、GYAO!の疑似プレイヤー（再生位置・視聴履歴・視聴済み）、ミュージックの再生位置・続きから再生・最近再生した項目、投票の履歴（投票のたびに記録が積み上がる）、Yahoo!ニュースのリアクション（そう思う／そう思わないは一方だけ・1回だけ・取消不可）と既読、Twitterのいいね／RT／返信の保持（開き直しても残る）、通話の途中終了の扱い（次回起動時に通話履歴へ記録し、第1回発表直前の電話CALL1はかけ直せる。着信の通話時間は応答してから数える）、ロック画面の通知タップで対応アプリへ進む遷移、ステータスバーのインジケータ出し分け（Wi-Fi接続中は「4G」の字を出さない／モバイルデータOFFで「4G」も消える／機内モードで電波バーが✈に置き換わる）、ロック画面でステータスバーの時計を出さない表示、コントロールセンターのWi-Fi・モバイルデータのグリフと色、LINEのトーク内検索ハイライト（化けの是正・新しい側のヒットへ寄せる）と未読バッジの「99+」上限表示、LINE下部タブ「トーク」の合計未読バッジ、通知バナーの再通知時の差し替え表示（表示中に新しい通知が届くと最新へ差し替わり、自動消滅までの時間を数え直す）と本文の最大2行表示、Twitterのフォロー状態（公式プロフィール・おすすめユーザー）の保持など、操作したときの振る舞いを当時の実物へ寄せている。v8.71からは機能フェーズとして、GYAO!のマイリスト（話数の詳細から登録し、一覧のマイリスト面と★印で辿れる。登録はセーブに残る）とミュージックのお気に入り（各曲の♥登録と「♥ お気に入り」の絞り込み。こちらもセーブに残る）、通知バナーの上スワイプ消去を新設した。v8.72からはメディア追加フェーズとして、生成のオリジナルBGM2曲（プロローグで流れる「坡州の朝」と後日談で流れる「合宿の夜」。ミュージックのリストからも聴ける）と、トークの送受信・投票や分量配分の確定で鳴る効果音3種を足した（いずれも生成音源のみで、著作権のある楽曲そのものは入れていない。効果音は設定のサウンドON/OFFと音量に従う）。v8.73では場面BGMの残りの空白にも生成のオリジナルBGMを5曲（放送〜投票期間の「放送の日々」、グループバトル編成の「結成の日」、放送〜第2回投票の「帰り道」、コンセプト評価マッチングの「仮センター」、第3部の再編・練習の「月明かりの廊下」）を足してplaySceneのある全場面に行き渡らせ、効果音には順位発表で大翔の名前が呼ばれる瞬間に鳴るチャイムを1種足した（計4種。playSceneを持たない編集確定の合図と通話の場面は無音のまま据え置き）。v8.74では、場面の台詞にボイスを付ける仕組みを新設し（トークや思い出のボイス吹き出しと同じ再生の作法で、今後の追加ボイスも同じ仕組みで足せる）、第2回順位発表で大翔が生き残った直後の台詞に生成ボイスを付けた。あわせてミュージックの曲目リストは、見出しが「課題曲」のままBGMも並んでいたのを、「課題曲」と「BGM」の2つのまとまりに分けて表示するよう是正した（並び順と前／次の曲への移動は従来どおり）。v8.75では、playSceneを持たない5場面（編集確定の合図と、第2回順位発表の前夜・ファイナル前夜の通話）へ音を付ける場合の仕組み拡張の範囲と設計案を棚卸しし、判断材料を恒常記録に残した（実装はしていない。編集確定の合図は画面も滞在時間も持たない通過点でBGMを流す場がなく、確定・到着の効果音は既に鳴っている。通話はボイスが主役で、足すとしたら第2回順位発表の前夜だけにある着信から応答までの間が候補）。v8.76では、生成しておいた大翔のボイス2本（コンセプト評価の「半分は、なおさんのおかげやと思ってます」と、グループバトル本番後の「複雑です」）を、v8.74で新設した場面ボイスの仕組みで該当する台詞ステップへ併設した（生成枠の残量は約4秒しかなく、残りの候補だったポジション評価の決め台詞は生成していない）。v8.77では、メディア追加フェーズの締めとして音まわり全体（効果音4種・場面BGM全16場面・ボイス全14本）を横断で棚卸しし、尺ラベルが実測と全件一致することと、音量・ON/OFFの作法がそろっていることを確認した。あわせて、画面遷移で音楽とGYAO!は止まるのにボイス吹き出しだけ止まらない非対称を是正し、ボイスも遷移で止まる作法に統一した。点検のうえ据え置いた判断（Twitter通知タブに既読の仕組み自体がないこと、ロック画面の通知上限3件はレイアウト都合、コントロールセンターのタイルの文字ラベルは操作の可読性を優先した適応として据え置き、電池残量は消費・充電の根拠データがないため進行連動させず固定表示のまま据え置き、電池アイコンの形やロック画面のグリフ類は差分なし、LINEのルーム別通知トグルは通知が物語の進行合図そのもので干渉が大きいため実装しない判断を恒常記録に残した、など）も含め、新しい保存項目はいずれも旧セーブで欠けても壊れない形にし、結論はコード内の恒常メモに記録。v8.78では、本人の指示を受けてチャット（LINEトーク）の文章だけを大改稿した（全トークルームのメッセージ、トーク選択肢の文案、自由送信への定型返信。言い回し・温度・ユーモアは大きく変えたが、中身と流れ、選択肢の数・並び・効果は従来どおり。音声付きの文面は音声と一致させるため一字も変えず、地の文・場面の台詞・SNSやニュースの文章も対象外で不変）。
